# Instrucciones del Proyecto

## Control de Versiones (Git)
- Cada vez que el asistente realice modificaciones, correcciones o agregue nuevos archivos en este repositorio:
  1. Ejecutar `git add .`
  2. Ejecutar `git commit -m "<mensaje conciso y descriptivo en español>"`
  3. Ejecutar `git push origin main`
- Confirmar al usuario el resultado del commit y push realizado.

## Idioma y Comunicación
- Todas las comunicaciones, explicaciones, preguntas y opciones interactivas dirigidas al usuario deben formularse siempre en español.
